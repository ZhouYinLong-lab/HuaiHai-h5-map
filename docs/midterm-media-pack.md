## 资源性质

- 本轮图片均为项目原创 SVG 资料图，不是历史照片，也不是从第三方网站下载的照片。
- 图片用于中期审查演示，解决页面视觉空缺和资料结构展示问题。
- 图中路线、节点和纹理为视觉示意，不用于精确历史地图或导航。
- 正式上线前仍需替换为实地拍摄照片、纪念馆授权照片或版权明确的历史图像。

## 文件位置

```text
public/media/sites/{site-id}/cover.svg
public/media/sites/{site-id}/gallery-route.svg
public/media/sites/{site-id}/gallery-sources.svg
```

## 后续替换步骤

1. 将实拍或授权照片压缩为 WebP。
2. 替换对应点位下的 `cover.webp`、`gallery-01.webp` 等文件。
3. 修改 `src/data/sites.json` 中的 `image` 和 `gallery` 路径。
4. 为每张图片补充图注、来源、拍摄者或授权说明。
5. 运行：

```bash
npm run validate:content
npm run build
```
