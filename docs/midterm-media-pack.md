## 资源性质

- 本轮图片已从项目原创 SVG 示意图切换为公开资料页中的真实照片。
- 页面图注已标明来源页面，便于中期审查说明资料出处。
- 这些图片适合中期审查展示，不再冒充“项目原创示意图”。
- 正式上线前仍建议补充实地拍摄照片、纪念馆授权照片或更完整的版权说明。

## 文件位置

```text
public/media/sites/{site-id}/cover.jpg
public/media/sites/{site-id}/gallery-01.jpg
public/media/sites/{site-id}/gallery-02.jpg
```

## 后续替换步骤

1. 将实拍或授权照片压缩为 WebP。
2. 替换对应点位下的 `cover.webp`、`gallery-01.webp` 等文件。
3. 修改 `src/data/sites.json` 中的 `image` 和 `gallery` 路径。
4. 为每张图片补充图注、来源、拍摄者或授权说明。
5. 运行：

```bash
npm run validate:content
npm run build
```
